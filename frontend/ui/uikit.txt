Iconografía
Icono / Candado:

Se usa para seguridad y autenticación.
Identifica la pantalla de acceso o configuración de seguridad donde el tutor debe ingresar el PIN de verificación para realizar cambios o deshabilitar restricciones.

Icono / Campana:

Se usa para notificaciones y alertas del sistema.
Va a estar ubicado en la barra superior del panel principal para acceder al historial de avisos (ej: cuando se detecta un intento de ingreso fallido, cambios en las reglas de control parental o alertas de la app).


Icono / Usuario:

Se usa para el perfil y la gestión de cuenta.
Representa la sección del perfil del tutor o la selección de perfiles infantiles configurados en el dispositivo para administrar sus permisos individuales.


Icono / Busqueda:

Se usa para navegación y filtrado.
Va a estar dentro del panel de administración o historial de actividad para buscar rápidamente registros específicos, contactos bloqueados o reglas aplicadas.

Icono / Volver:

Se usa para navegar hacia atrás.
Va a estar ubicado en la esquina superior izquierda de los encabezados para regresar a la pantalla anterior sin guardar cambios accidentales o para cancelar un flujo.


Icono / Alerta:

Se usa para advertencias, errores o estados críticos.
Se acompaña de textos informativos en mensajes de confirmación (ej: “¿Estás seguro de que querés desactivar la protección?”) o en avisos de error cuando un PIN es incorrecto.
